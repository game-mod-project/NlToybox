## 0.27.1 뒤에 바뀐 것

- **지도 탭**(0.32.0, 0.32.1): 새 게임의 생성기 화면에서 영지의 생성 설정 17값(지형 5, 가장자리 막힘 4, 자원 8)을 보이고 고치고, 게임의 `regenerate_map()` 으로 다시 생성한다. 프리셋을 `mods\Aurie\NlToyBox.maps.txt` 에 이름으로 저장·불러오기. 자원의 단계는 자리의 수(철 4 → 광산 4개). 씨앗 고정은 뺐다(생성기가 씨앗 함수를 읽지 않는다).
- **이벤트 탭**(0.30.0, 0.31.0): 게임의 이벤트 61개의 표, 강제 발동(예약)과 바로 일으키기, 예약 취소, 확인된 가족만의 끝내기, 쿨다운 지우기.
- **도서관의 책**(0.31.3): 지식 탭의 둘째 탭 — 책 넣기·빼기, 모든 책 넣기, 모드가 넣은 책만 되돌리기.
- **영주 소환의 옵션**(0.31.5): 소환할 영주의 성별·나이·문화·역할 프리셋.
- **정원과 효과의 배율**(0.31.0~0.31.2): 주택·병영 정원 배율, 좋은 효과의 범위 배율, 나쁜 효과 없애기. 샌드박스·신 프리셋에 그 배율.
- **되돌리기**(0.28.0, 0.29.0): 역할 프리셋 되돌리기, 왕국 평판 떼기, 깡패 되돌리기. 이벤트 골라 일으키기, 지금 저장.
- **고침**: 새 게임의 영주관 배치에서 게임이 끝나던 것(즉시 건설의 깃발은 영주관이 놓인 뒤에만. 0.30.1), 좋은 효과의 범위를 켠 채 부팅하면 끝나던 것(0.31.4).
- 구조: 리팩토링 A·B·C(0.27.2, 0.27.3, 0.29.1). 조사 기록 `research/27` ~ `35`.

## 넣는 법

1. Aurie v2.0.2 와 YYToolkit v5.0.0c 가 게임에 놓여 있어야 한다. 이 저장소의 `tools/setup-aurie.ps1`이 그것들을 받아 게임에 놓고 `Norland.exe`를 패치한다(원본은 `backups/`에 보관한다). PowerShell 7 과 git 이 필요하다.

       git clone https://github.com/game-mod-project/NlToybox.git
       pwsh -File NlToybox/tools/setup-aurie.ps1

   게임 폴더가 스크립트의 기본값과 다르면 환경변수 `NORLAND_GAME_DIR`로 알려 준다.
2. 게임을 끈 채로 `NlToyBox.dll`을 `<게임 폴더>\mods\Aurie\`에 넣는다(0.27.1 의 DLL 이 있으면 덮어쓴다).
3. 게임을 켜고 **F8**을 누르면 모드창이 뜬다.

- 필요한 것: Microsoft Visual C++ 2015-2022 재배포 가능 패키지(x64).
- 빼는 법: `mods\Aurie\NlToyBox.dll`을 지운다. 게임을 패치 전으로 되돌릴 때는 `tools/restore-game.ps1`.
- 모드가 만드는 설정 파일: `mods\Aurie\NlToyBox.settings.txt`(배율), `NlToyBox.cheats.txt`(켠 치트), `NlToyBox.maps.txt`(지도 프리셋). 빼면서 함께 지워도 된다.

## 알아 둘 것

- **게임 버전에 묶여 있다.** 위의 버전에서만 쟀다. 게임이 갱신되면 다시 재야 한다.
- 창에서 `(?)`나 "(확인 전)"이 붙은 항목은 값을 쓰거나 게임의 함수를 부르는 것까지만 봤고, 효과를 플레이에서 확인하지 못한 것이다.
- 세이브는 미리 사본을 떠 둔다. 보증은 없다(`LICENSE`의 15, 16절).
- 게임 파일에서 뽑은 것(`refs/`), 게임 실행 파일의 사본(`backups/`), 제3자 배포물(`downloads/`)은 저장소와 묶음에 없다.
