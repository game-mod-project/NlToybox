# 지도 탭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 새 게임의 생성기 화면에서 모드창의 "지도" 영역이 영지의 생성 설정 17값(지형 5·막힘 4·자원 8)을 보이고 고치게 하고, 게임의 `regenerate_map()` 으로 다시 생성시키며, 프리셋을 이름으로 저장·불러오고, 원격 `map …` 을 더한다.

**Architecture:** 러너에 기대지 않는 표·범위·프리셋 파일·원격 낱말·글은 `src/core/MapPlan`(시험 `tests/native/test_map.cpp`). 새 모듈 `src/MapGen.cpp`(`NlMapGen`)가 생성기 화면의 판정, 1초 스냅샷, 큐의 일(값 쓰기·다시 생성·원래대로·프리셋), 패널 그리기, 원격을 맡는다(Season·Events 와 같은 꼴: 제 뮤텍스, `g_Busy`, 큐의 상한). 씨앗 고정은 `NlRecorder::Override` 로 `get_generator_seed()` 의 반환값을 바꾸는 길이되 확인 전에는 켜지지 않는다.

**Tech Stack:** C++20, Aurie + YYToolkit v5.0.0c, Dear ImGui v1.91.9. 빌드 `tools/build.ps1`, 코어 시험 `tools/test-native.ps1`.

**Spec:** `docs/superpowers/specs/2026-10-07-map-tab-design.md`

## Global Constraints

- 그리는 쪽(`Draw*`)에서 러너를 부르지 않는다. 창은 청만 쌓고 틱이 한다. `RValue` 를 틱 너머로 들지 않는다.
- 게임의 함수는 게임이 부르는 꼴을 본 것만 부른다: `MapPreviewController.regenerate_map()` 은 인자 없이(research/31 의 기록). 세터(`set_lakes` 들)는 부르지 않고 칸에 바로 쓴다. `get_generator_seed()` 의 훅은 생성기가 그 함수를 읽는 것을 본 뒤에만 켠다(그 전에는 `SeedHookVerified()` 가 거짓이고 켜지지 않는다).
- 쓴 뒤에는 다시 읽어 판정한다. 부르기 전에 로그를 남긴다. 생성기 화면이 아니면(게임 안, 메인 메뉴) 쓰지도 부르지도 않는다.
- 게임 파일의 값은 레포에 옮기지 않는다(표에는 열쇠·칸·범위만. 범위는 research/31 에서 본 단계 수).
- 프리셋 파일 `mods\Aurie\NlToyBox.maps.txt` 는 사용자의 설정이다. 막힘 4개는 프리셋에 넣지 않는다.
- 모드창의 글에 기호(화살표, 별)를 쓰지 않는다. 한글과 라틴-1 만.
- 버전 `0.32.0`(develop 331aa50 가 0.31.3 다. 2026-10-08 에 그 위로 올렸다). 빌드는 `build ok` 이고 `warning C` 가 없어야 한다. 코어 시험은 모두 통과(지금 131 → 끝에 134).
- 게임 켜기는 Task 7 에서 **두 번**: 확인 1번(사용자가 생성기 화면까지 간다) + 확인 뒤의 고침(`SeedHookVerified`·글)을 넣은 DLL 의 적재 판정 1번(`check-load.ps1`). 켜기 전에 사용자에게 알린다. 커밋은 가지 `feat/map-tab` 에.

## Review Focus

- 게임 안(영주관을 놓은 뒤)이나 메인 메뉴에서 `map set`·`map regenerate` 가 오면 쓰지도 부르지도 않고 "새 게임의 지도 화면(영주관 배치 전)에서만 됩니다" — Task 1 의 `MapScreen(…, InGame=true)` 시험, Task 3 의 코드.
- 프리셋 파일의 줄에 범위 밖의 수·소수·모르는 열쇠·수가 아닌 값이 있을 때: 범위 밖은 당기고 소수는 내리고, 모르는 열쇠나 수가 아닌 값이 든 줄은 버린다 — Task 2 의 `ParseMapPresets` 시험.
- 같은 이름으로 다시 저장하면 한 줄로 덮어쓴다(두 줄이 되지 않는다) — Task 2 의 `UpsertPreset`·`FormatMapPresets` 시험.
- `map set blocked_up=1` 은 받는다(창에서 고칠 수 있다)지만 프리셋에는 들지 않는다 — Task 2 의 `FormatMapPresets`(막힘 생략)과 Task 2 의 원격 시험.
- 씨앗 고정은 확인 전이라 창의 체크와 `map seed` 가 모두 "확인 전"으로 거절된다 — Task 1 의 `SeedHookVerified()`·`MapReport(Seed,'u')` 시험, Task 5 의 코드.

	Test("지도: 설정 표 17줄, 범위, 자리, 화면의 판단, 결과의 글", [] {
		// research/31: 영지의 생성 설정 17개. 지형 5(창의 단계 수가 범위), 막힘 4, 자원 8(범위 미확인이라 0~9).

			if (knob.Group == MapGroup::Resource) resource++;
			if (knob.InPreset) preset++;

	bool GoodPresetName(const std::string& Name)
	{
		if (Name.empty() || Name.size() > 32)
			return false;
		for (const unsigned char c : Name)
			if (c == ' ' || c == '=' || c < 0x20 || c == 0x7f)
				return false;
		return true;
	}

	namespace
	{
		// "열쇠=수" 를 읽는다. 모르는 열쇠나 수가 아닌 값은 거짓(Why). 막힘 열쇠와 seed 는 Out 에 넣지 않고 참(Skip).
		bool ReadPair(const std::string& Word, MapPreset& Out, bool& Skip, std::string& Why)
		{
			Skip = false;
			const size_t eq = Word.find('=');
			if (eq == std::string::npos || eq == 0)
			{
				Why = "expected key=value: " + Word;
				return false;
			}
			const std::string key = Word.substr(0, eq), text = Word.substr(eq + 1);
			double value = 0;
			if (!ParseNumber(text, value))
			{
				Why = "not a number: " + Word;
				return false;
			}
			if (key == "seed")
			{
				Out.Seed = std::floor(value);
				Skip = true;
				return true;
			}
			const MapKnob* knob = FindMapKnob(key);
			if (!knob)
			{
				Why = "unknown key: " + key;
				return false;
			}
			if (!knob->InPreset)
			{
				Skip = true;		// 막힘은 프리셋에 들지 않는다
				return true;
			}
			Out.Values[key] = ClampMapValue(*knob, value);
			return true;
		}
	}

	std::vector<MapPreset> ParseMapPresets(std::istream& In)
	{
		std::vector<MapPreset> out;
		std::string line;
		while (std::getline(In, line))
		{
			if (!line.empty() && line.back() == '\r')
				line.pop_back();
			std::istringstream words(line);
			std::string head, name;
			if (!(words >> head) || head != "preset" || !(words >> name) || !GoodPresetName(name))
				continue;
			MapPreset preset;
			preset.Name = name;
			bool ok = true;
			std::string word, why;
			while (ok && words >> word)
			{
				bool skip = false;
				ok = ReadPair(word, preset, skip, why);
			}
			if (ok)
				UpsertPreset(out, std::move(preset));
		}
		return out;
	}

	std::string FormatMapPresets(const std::vector<MapPreset>& Presets)
	{
		std::vector<const MapPreset*> sorted;
		for (const MapPreset& preset : Presets)
			sorted.push_back(&preset);
		std::sort(sorted.begin(), sorted.end(), [](const MapPreset* A, const MapPreset* B) { return A->Name < B->Name; });
		std::string out = "# NlToyBox 의 지도 프리셋. 지도 탭에서 저장하면 여기에 쓰인다. 줄: preset <이름> <열쇠>=<수> … seed=<수>(-1 은 무작위).\n";
		for (const MapPreset* preset : sorted)
		{
			out += "preset " + preset->Name;
			for (const MapKnob& knob : MapKnobs())
			{
				const auto found = preset->Values.find(knob.Key);
				if (knob.InPreset && found != preset->Values.end())
					out += std::string(" ") + knob.Key + "=" + Shortest(found->second);
			}
			out += " seed=" + Shortest(preset->Seed) + "\n";
		}
		return out;
	}

	void UpsertPreset(std::vector<MapPreset>& Presets, MapPreset Preset)
	{
		for (auto it = Preset.Values.begin(); it != Preset.Values.end();)
		{
			const MapKnob* knob = FindMapKnob(it->first);
			if (!knob || !knob->InPreset)
				it = Preset.Values.erase(it);
			else
			{
				it->second = ClampMapValue(*knob, it->second);
				++it;
			}
		}
		for (MapPreset& have : Presets)
			if (have.Name == Preset.Name)
			{
				have = std::move(Preset);
				return;
			}
		Presets.push_back(std::move(Preset));
	}

	bool ErasePreset(std::vector<MapPreset>& Presets, const std::string& Name)
	{
		for (auto it = Presets.begin(); it != Presets.end(); ++it)
			if (it->Name == Name)
			{
				Presets.erase(it);
				return true;
			}
		return false;
	}

	const MapPreset* FindPreset(const std::vector<MapPreset>& Presets, const std::string& Name)
	{
		for (const MapPreset& preset : Presets)
			if (preset.Name == Name)
				return &preset;
		return nullptr;
	}

	bool MapCommandFromParts(const std::string& Target, const std::map<std::string, std::string>& Options, MapCommand& Out, std::string& Why)

			Out.Act = MapAct::Set;

				return false;
			}

			else if (op->second == "load") Out.Act = MapAct::PresetLoad;
			else if (op->second == "delete") Out.Act = MapAct::PresetDelete;
			else
			{

				return false;
			}
			if (!GoodPresetName(name->second))
			{
				Why = "map preset: bad name (1-32 bytes, no space or =)";
				return false;
			}

			return true;

		if (Target == "seed")
		{
			const auto value = Options.find("value");
			if (value == Options.end())

				return false;

			Out.Act = MapAct::Seed;

				return false;
			}
			Out.Seed = std::floor(seed);
			return true;
		}
		Why = "map needs one of: show, set, regenerate, restore, preset, seed";
		return false;
	}

void NlMapGen::Tick(double Now, bool Visible)
{
	std::lock_guard lock(g_Mutex);
	if (g_Busy)
		return;
	const bool read = Visible && Now >= g_NextRead;
	if (g_Queue.empty() && !read)		// 시각부터 본다(이 틱은 오브젝트 이벤트마다 불린다)
	{
		if (!Visible && g_Now.Ready)
			g_Now = Snapshot{};		// 패널을 다시 열면 새로 읽은 것을 보인다
		return;
	}
	const NlCore::ScopedFlag busy(g_Busy);
	if (!g_Queue.empty())
	{
		const MapCommand command = g_Queue.front();
		g_Queue.pop_front();
		Remember(DoNow(command));
		g_NextRead = 0;			// 한 뒤에는 바로 다시 읽는다
	}
	if (Visible && Now >= g_NextRead)
	{
		g_NextRead = Now + 1;
		ReadSnapshot();
	}
}

std::vector<std::string> NlMapGen::Do(const NlCore::MapCommand& Command)
{
	std::lock_guard lock(g_Mutex);
	if (g_Busy)
		return { "busy" };
	const NlCore::ScopedFlag busy(g_Busy);
	if (Command.Act == MapAct::Show)
	{
		ReadSnapshot();
		std::vector<std::string> lines;
		lines.push_back(std::string("screen ") + (g_Now.Screen ? "yes" : "no"));
		if (g_Now.Screen)
		{
			for (const MapKnob& knob : NlCore::MapKnobs())
			{
				const size_t i = IndexOf(knob);
				lines.push_back(std::string(knob.Key) + " " + (g_Now.Read[i] ? NlCore::Shortest(g_Now.Values[i]) : "?") + " (original " + (g_Now.StashedRead[i] ? NlCore::Shortest(g_Now.Stashed[i]) : "?") + ")");
			}
			lines.push_back("seed " + (g_Now.SeedRead ? NlCore::Shortest(g_Now.Seed) : std::string("?")) + (g_SeedOn ? " (fixed " + NlCore::Shortest(g_SeedValue) + ")" : std::string()));
		}
		std::string names;
		for (const std::string& name : g_Now.Presets)
			names += (names.empty() ? "" : ", ") + name;
		lines.push_back("presets: " + (names.empty() ? std::string("(none)") : names));
		return lines;
	}
	const std::string text = Remember(DoNow(Command));
	g_NextRead = 0;
	return { text };
}

	std::string SeedNow(const MapCommand& C)
	{

			return NlCore::MapReport(MapAct::Seed, 'u', std::string());

		{
			if (!g_SeedHook.empty())

		g_SeedHook = name;
		g_SeedOn = true;
		g_SeedValue = C.Seed;
		return NlCore::MapReport(MapAct::Seed, 'd', NlCore::Shortest(C.Seed));
