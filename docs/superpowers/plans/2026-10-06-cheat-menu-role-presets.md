# 인물의 역할 프리셋 — 실행 계획

**목표:** 인물 탭에서 영주 하나를 골라 역할 프리셋(왕, 내정, 학자, 교관, 장군, 결투, 정치가, 음모, 관계, 종교, 무역, 생산, 교육)을 입힌다:
그 역할의 능력치를 올리고, 맞는 재능을 붙이고, 해로운 특성을 뗀다.

**스펙:** `docs/superpowers/specs/2026-10-05-cheat-menu-design.md` §8(인물). 사용자 요청 2026-10-06.

**사용자가 정한 것 (2026-10-06):**

- 능력치는 표대로, **올리기만** 한다: 핵심 20, 보조 15. 이미 더 높은 것과 프리셋에 없는 것은 건드리지 않는다.
- 특성은 표의 재능을 붙이고, **그 역할에 해로운 특성도 뗀다**. 무엇이 떼어지는지 적용 전에 보인다.
- 게임 실행 2번.

## 근거 (추측 금지)

| 쓰는 것 | 어디서 봤나 |
|---|---|
| 능력치 쓰기: `__soul.__skills.__level.<열쇠>`(0~20) | `research/11`. 게임의 인물 창이 그 수를 보인다 |
| 특성 붙이기·떼기: `Traits.trait_attach("이름")`, `trait_detach("이름")` | `research/11`. 게임이 글 하나로 부른다 |
| 재능을 한 사람에게 여럿 붙이기 | `research/21` 실행 3: 71번 붙여 71번, 한 영주에게 30개, 서로 막는 것 없음 |
| 특성의 뜻 | 게임의 설명 글(`localization\hints*.csv`)을 읽고 골랐다. **재능마다의 효과를 플레이에서 재지는 않았다** |
| 프리셋의 특성 74개(표의 칸은 123개)가 게임에 있는가 | 게임의 특성 281개의 이름과 맞춰 봤다(없는 것 0개) |
| 능력치의 게임 이름: `main.csv`의 `actor.skill.<열쇠>`. **전투만 `actor.skill.fight`** | 게임 파일(줄 9개: 능력치 여덟과 `points_remain`). 모듈이 실행 중에 읽는다(레포에 글을 옮기지 않는다) |

재지 않은 것: 해로운 특성(`nervous`, `coward`, `pacifist`, `stupidity`, `contemptuous`, `sarcastic`, `cynic`, `envious`, `greedy`)이 `trait_detach`로 떼어지고
그대로 남는가. 실행 1에서 잰다.

## 파일

- `src/core/RolePlan.hpp/.cpp` (새로): 프리셋의 표(`RolePresets`), `FindRole`, `CheckRoles`, `PlanRole`(올릴 능력치, 붙일 것, 뗄 것), `RoleReport`(결과의 글).
- `src/core/PeoplePlan.*`: `PersonAct::Role`(낱말 `role`, 이름은 프리셋의 Id, 한 사람을 짚어서만).
- `src/core/Localization.*`: `SkillCaptionKey`.
- `src/core/RemoteCommand.*`: `person <uuid> role name=<Id>`.
- `src/People.cpp`: `One()`의 `Role`, `Attach`(붙이고 다시 읽기), 인물 탭의 "역할 프리셋"(고르기, 미리 보기, 단추), 능력치의 게임 이름.
- `tests/native/core_tests.cpp`: 표(Id 13개, 수는 20·15 뿐, 넣지 않기로 한 특성, 크기), 계획(올리기만, 없는 능력치, 가진 것만 떼기), 결과의 글, 명령의 검사.

## 검토에서 볼 것

- 그 자리의 사람이 바뀌었을 때(인물이 드나듦) 다른 사람에게 붙이거나 떼지 않는가.
- 일부만 된 적용의 글이 한 것과 못 한 것을 그대로 말하는가.
- 미리 보기(읽어 둔 값)와 틱의 적용(다시 읽은 값)이 어긋날 때의 결과.
- 주민(능력치가 전투뿐)·손님에게 눌렀을 때.
- 창의 글이 재지 않은 것을 사실처럼 말하지 않는가.

## 결과

모듈 0.24.0, 화면을 다듬은 0.24.1(사용자가 실행 한 번을 더 승인했다). 잰 것은 `research/22-role-presets.md`.

- **됐다**: 프리셋 13개를 영주 넷에게 입혀 하지 못한 것 0(붙이기 85번, 떼기 15번). 해로운 특성 아홉 종이 떼어진다. 더 높은 능력치와 표에 없는 능력치는 그대로다.
  같은 프리셋을 다시 입히면 "이미 그대로입니다". 두 시간 뒤에도 남는다. 인물 탭의 미리 보기와 결과의 줄이 그려진다. 적재 판정 통과.
- **독립 검토**(게임을 켜기 전): Critical 0, Important 1, Minor 14. 고친 것 — 붙이기 뒤에 떼던 차례를 떼기 먼저로(`RoleSteps`), 걸음마다 특성을 다시 읽기(`RoleStepNeeded`),
  전투의 이름 열쇠(`actor.skill.fight`. 검토가 게임 파일로 잡은 사실 오류), 시험 주석의 게임 명칭 셋, 결과를 단추 아래에, 로그의 집계 줄.
- **알게 된 것**: `coward`를 가진 사람에게 `fearless`·`brave`가 함께 붙는다. `stupidity`를 떼면 생각의 합이 25 내려간다.
  붙인 재능(`redeemer`, `musician`)의 행동을 게임이 돌리려다 대상을 못 찾았다는 경고가 게임의 오류 파일에 남는다.
- **0.24.1**: 0.24.0 의 화면에서 단추 옆의 요약 글이 잘리고 뗄 특성이 스크롤 아래에 있던 것을 고쳤다 — 요약을 제 줄로(`RolePreview`), 뗄 특성을 먼저,
  `stupidity`를 떼기 전의 안내(`RemoveNote`), 능력치의 글이 줄 사이에서 갈리지 않게. 화면 셋과 적재 판정으로 확인했다.
- **남은 것**: 재능마다의 효과, 세이브에 남는지, 주민·손님에게 입혔을 때는 재지 않았다. 요약("떼고, 붙입니다")과 결과의 글("붙이고, 뗐습니다")의 차례가 다르다.
- **미룬 것**(검토의 Minor): 부른 직후 자리가 바뀌면 "하지 못한 것"으로 센다, 미리 보기의 수가 게임에 없는 특성을 센다, 미리 보기와 계획의 능력치 판정이 다른 식이다,
  보호된 특성의 방어가 표의 시험뿐이다, `CheckRoles`의 거짓 가지의 시험이 없다, 능력치 이름을 거르는 조건에 시험이 없다, `RoleReport`의 쓰이지 않는 가지.
